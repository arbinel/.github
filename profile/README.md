Arbinel is an AI-friendly soft fork of [Forgejo](https://forgejo.org), the self-hosted software forge, open to contributions from anyone.
It runs [codefloe.com](https://codefloe.com) and adds what a public, multi-tenant forge needs beyond Forgejo, while tracking every Forgejo release.

- **Always compatible with Forgejo.** Arbinel stays compatible with Forgejo in both directions, and every release names the Forgejo release it is built on.
- **Opt-in features.** Quotas, billing, high availability, Pages and request budgets are off by default.
- **Open to anyone.** Contributions written with the help of LLMs and coding agents are welcome, held to the same standard as any other.

## Where to find us

Development happens on CodeFloe, not GitHub:

- Source, issues and pull requests: [codefloe.com/arbinel/arbinel](https://codefloe.com/arbinel/arbinel)
- Production instance: [codefloe.com](https://codefloe.com)

This GitHub organization holds the `arbinel` namespace for distribution channels such as Ansible Galaxy.
